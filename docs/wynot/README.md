## How to use this folder

1. Read the module that matches your change type.
2. Apply the corresponding checklist in your implementation.
3. Confirm compliance in your pull request summary.

## Handbook integration model

When official WYNOT handbooks are imported, place source material under
`docs/wynot/handbooks/` and map requirements into the standards modules above.
