# AEO About Page Blueprint (2026)

This file captures the WYNOT AEO system prompt module for building
high-information-density About pages that can act as source-of-truth assets for
AI retrieval systems.

## Objective

- Structure company information for AI-native retrieval and summary extraction.
- Prioritize factual clarity, search-intent alignment, and standalone context in
  every section.

## Structural requirements

- BLUF first section in roughly the first 150 to 200 words.
- Include legal entity name, industry, audience, core offer, founder/founding
  facts, and HQ location.
- Use question-form H2/H3 headings aligned with natural language queries.
- Follow each heading with a concise high-density paragraph suitable for direct
  AI snippet extraction.

## E-E-A-T requirements

- Use verifiable data points when available: dates, named leadership, role
  credentials, compliance standards, measured outcomes, and formal milestones.
- Keep leadership bios factual and credential-focused.

## Mandatory page sections

- Entity definition section (`About [Company Name]`).
- Operational scope Q and A (services and audience served).
- Leadership and authority section.
- Corporate FAQ section with direct one- to two-sentence answers.

## Language constraints

- Avoid buzzword-heavy promotional phrasing.
- Favor descriptive nouns and verifiable verbs.
- Limit pronoun overuse when explicit entity naming improves clarity.
- Ensure each section can stand alone outside full-page context.

- Apply this blueprint for WYNOT About pages, tribe entity pages, and public
  authority pages where AI retrieval accuracy is critical.
